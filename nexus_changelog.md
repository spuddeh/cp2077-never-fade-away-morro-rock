# Changelog

### [v1.0.2]
- Fix: the song is now added to the game's sound event list by AudioXL, and the mod no longer edits game files at the moment every other mod does. AudioXL 0.6.0 names both as a cause of crashes at launch when several sound mods are installed.
- Note: now requires AudioXL 0.6.0 or newer. With an older AudioXL, redscript reports a compile error at launch.

### [v1.0.1]
- Fix: Restore Nebula's track no longer goes missing from Growl FM beside this mod. No patch is needed.
- Fix: other mods that edit the game's audio data at load no longer lose their changes beside this mod.
- Note: the Restore Nebula Compatibility Patch is no longer needed; delete it if you installed it.
- Note: now requires AudioXL 0.4.3 or newer. With an older AudioXL, redscript reports a compile error at launch.

### [v1.0.0]
- First release. Adds the end-credits cover of Never Fade Away to 107.3 Morro Rock Radio, in normal
  rotation.
- Plays the credits recording already in your game, with the silence at each end trimmed. The mod
  ships no audio.
- Shows as P.T. Adamczyk, Olga Jankowska - Never Fade Away (Samurai Cover), in every language the
  game ships.
